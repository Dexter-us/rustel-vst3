Rustel for Windows — portable ZIP

This archive has no installer and does not change Windows settings. Extract the
whole ZIP to a folder you want to keep. Keep Rustel.vst3 and CsoundRuntime
together in that folder; Rustel finds its bundled Csound automatically.
Load and Save start in a Scores subfolder beside the plugin bundle and create
that folder when needed, so saved scores move with the portable files.

In VSTHost, add the extracted folder to the VST3 plugin scan paths and rescan.
If you prefer the standard VST3 folder, copy both Rustel.vst3 and CsoundRuntime
there as sibling folders. Do not copy only the inner Rustel.vst3 binary.

The archive also contains rustel.exe, the full upstream command-line app, and
Csound 6.18.1. The CLI can be run from the extracted folder in PowerShell:

  .\rustel.exe --help

Csound is off by default. Enable "Allow native Csound" only for scores you
trust; native Csound opcodes run with the same permissions as your DAW.

The Microsoft Visual C++ 2015–2022 x64 runtime may be needed for Csound. If
Windows reports a missing VCRUNTIME or MSVCP DLL, install Microsoft's official
x64 redistributable:
https://aka.ms/vs/17/release/vc_redist.x64.exe

This bundle supports Csound 6.18.1 x64, not Csound 7.
